## The research question

Missing values can change the conclusions drawn from omics experiments, yet the best imputation method depends on the dataset and the analytical question. Building on the imputomics web server and R package, this project broadens the framework from metabolomics to multiomics and makes methods easier to compare through common interfaces and curated benchmarks.

## What the project sets out to do

01 / RESEARCH AIM

### Curate methods and datasets

Review imputation algorithms and annotate their assumptions, applications and omics-specific characteristics.

02 / RESEARCH AIM

### Build a common interface

Develop a standardised wrapper for methods across genomics, transcriptomics, proteomics and metabolomics.

03 / RESEARCH AIM

### Compare what matters

Benchmark methods using error, correlation, interpretability and downstream tasks, and share an open repository of algorithms and datasets.
